# TierMaker VN - Bảng Xếp Hạng Rapper Việt Nam 🎵🏆

Ứng dụng web xếp hạng trực tuyến lấy cảm hứng từ TierMaker và chuẩn theo mẫu xếp hạng Rapper Việt Nam.

## ✨ Các Tính Năng Nổi Bật

1. **Chuẩn giao diện như ảnh mẫu**:
   - Các bậc xếp hạng mặc định: **A - B - C - D - E - F - G** cùng mã màu pastel chính xác.
   - Hỗ trợ đổi nhanh sang kiểu Gaming (**S - A - B - C - D - F**) hoặc kiểu Đỉnh Cao (**GOAT / Huyền Thoại**).
2. **Kéo thả mượt mà (Drag & Drop)**:
   - Kéo ảnh từ Kho ảnh vào bất kỳ bậc nào.
   - Kéo thả di chuyển qua lại giữa các bậc hoặc thay đổi thứ tự.
   - Kéo thả ngược về kho ảnh để hủy xếp hạng.
   - **Chạm/Click chọn nhanh**: Hỗ trợ click vào bất kỳ thẻ rapper nào để mở menu chọn nhanh bậc (rất tiện lợi trên điện thoại).
3. **Tải ảnh về máy (Download PNG 2K)**:
   - Xuất bảng xếp hạng thành file ảnh PNG độ nét cao (Retina 2x), không bị mờ hay vỡ hạt khi đăng lên Facebook, TikTok, Discord.
   - Hiệu ứng pháo hoa chúc mừng khi tải ảnh thành công.
4. **Kho ảnh 28 Rapper Việt Nam nổi tiếng**:
   - Đen Vâu, Suboi, Binz, Karik, JustaTee, Rhymastic, Wowy, B Ray, HIEUTHUHAI, MCK, tlinh, Low G, Andree Right Hand, BigDaddy, LK, DSK, GDucky, 24k.Right, Pháo, Double2T, Obito, 16 Typh, Tage, Gill, Rhyder, Pháp Kiều, HURRYKNG, Captain Boy...
5. **Tải thêm ảnh tùy biến**:
   - Bấm **"Tải ảnh từ máy"** để chọn nhiều ảnh từ máy tính.
   - Hỗ trợ kéo thả trực tiếp file từ máy tính vào trình duyệt.
   - Thêm ảnh qua đường dẫn link URL.
6. **Tùy chỉnh bậc xếp hạng**:
   - Bấm vào tên bậc để đổi tên trực tiếp.
   - Bấm biểu tượng bánh răng để đổi màu sắc với bảng màu phong phú.
   - Thêm hàng ở trên, thêm hàng ở dưới, di chuyển hàng lên/xuống, hoặc xóa hàng.
7. **Lưu tự động (LocalStorage)**:
   - Không bị mất kết quả khi F5 hoặc tải lại trang.

## 🚀 Hướng Dẫn Chạy Ứng Dụng

Ứng dụng đang chạy sẵn tại:
```
http://localhost:5173/
```

Nếu muốn khởi động lại từ terminal:
```bash
npm run dev
```

Nếu muốn đóng gói (build) thành trang web tĩnh:
```bash
npm run build
```
Thư mục xuất ra nằm trong `dist/`.
